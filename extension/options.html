Installer Ollama / erreur 403
  1. Installer Ollama : https://ollama.com/download
  2. Télécharger le modèle : ollama pull qwen3.5 (environ 7 Go, carte graphique 8 Go+ conseillée)
  3. Si le test affiche « 403 » : ajouter la variable d'environnement Windows OLLAMA_ORIGINS = moz-extension://*,chrome-extension://*, puis redémarrer Ollama.
